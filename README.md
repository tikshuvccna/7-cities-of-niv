# שבע הערים של ניב ⛵✨

משחק הרפתקאות וגילוי בעברית, בהשראת הקלאסיקה **"שבע ערי הזהב"** (Dan Bunten / Ozark Softscape, 1984).

ניב — קברניט ומצייר מפות הגון ומכבד — יוצא למסע אל יבשת לא מוכרת כדי למצוא **שבע ערים**, לפתור את הבחינה של כל אחת, ולאסוף שבע **אבני אור**.

## מה שונה מהמקור?
| המקור (1984) | שבע הערים של ניב |
|---|---|
| קונקיסטדור שיכול לתקוף ולכבוש | ניב **לא תוקף אף אחד**: מתנות, שיחה, סחר ועזרה לנזקקים |
| חיפוש זהב | חיפוש אור, ידע וחברות — כבוד הוא מדד הדירוג |
| ערים כיעד לביזה | כל עיר היא בחינה: פנסים, חידות, מבוך, גשר, מאזניים, כוכבים ומבחן יושרה |

מהמחקר הרחב על המקור נוספו גם: אתגר ארקייד של **גישה אל ראש הכפר** (מחסום שפה, מתנה מסיחה), **באר ובית ספר** כמקלט (במקום מיסיון/מבצר), ו**דיווח למועצה** עם קידום בדרגות לפי אחוז המפה שנחקר.

הנאמנות למקור: 3 רמות קושי, מפה קבועה או אקראית, הפלגה וירידה לחוף, ערפל חקר, מזון וצוות, מגע עם שבטים, מגבלת זמן ודירוגים.

## הרצה
פתחו את `index.html` בדפדפן, או הגישו בתיקייה: `npx http-server .`

בקרה: חצים / WASD · רווח או Enter לפעולה · Esc תפריט · M צליל. במכשיר מגע יש כפתורים על המסך.

הכל נוצר בקוד (Canvas + WebAudio) — ללא קבצי מדיה חיצוניים.
